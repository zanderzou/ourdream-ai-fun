OurDream's help says reference photos cannot be uploaded. Keep the visual continuity in a written sheet about a fictional adult. Start with an age range, two recognizable design details, and the clothing needed for the scene. Give location and action their own lines.

## Change the environment without changing the person

Start with an invented lighthouse keeper in their forties, wearing a red waterproof jacket and round glasses. Scene one places the keeper at a kitchen table. Scene two places the keeper on the lighthouse stairs. Keep the design details steady and add the environment and lighting separately.

![Choose two stable visual details. Separate changing scene inputs. Save the exact wording.](/assets/editorial-ourdream-prep-text-only-character-reference-sheet.png)

## Check what stayed consistent

Read both images at a usable size. If the first detail disappears, repeat it earlier in the next text prompt or choose simpler framing. Save the input that produced a useful reference. OurDream's prompt help describes variation, so treat each result as an individual candidate.
