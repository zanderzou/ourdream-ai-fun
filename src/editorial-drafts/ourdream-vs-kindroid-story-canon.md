OurDream AI vs Kindroid for a fictional project should distinguish what the character knows from how the character looks. A generated portrait can appear consistent while the dialogue changes a world fact. A well-followed story instruction can coexist with a visual detail you did not request.

This article reviews official information on October 8, 2026. It provides an original non-explicit character exercise and reports no rendered samples or comparative adherence scores.

## Write a compact canon record

Imagine an adult fictional botanist named Vale who works in a glasshouse on a floating island. Vale wears a green field jacket, records plant observations and asks visitors before taking them into the restricted archive.

The island and occupation are story facts. The jacket is a visual preference. Asking before entering the archive is a behavior and player-choice requirement. Keep these in separate lines so you can diagnose which part fails.

| Specification | What would count as a mismatch? |
|---|---|
| Floating-island glasshouse | Dialogue places the scene in another setting |
| Botanist role | Character invents an unrelated occupation |
| Green field jacket | Generated appearance changes the intended garment |
| Archive permission | Reply says the visitor already entered |
| Current task | Conversation abandons the agreed plant observation |

## Compare supported setup controls

Inspect the current OurDream character workflow and where it accepts written details. Its help center states that reference-photo uploads are not allowed. Do not build a test that depends on uploading a real person's portrait or treat that restriction as a reason to use another person's image elsewhere.

Kindroid documents personality setup. Use an original fictional specification in supported controls and keep any permitted visual input separate from the dialogue test. Record the actual account and mode, because a public feature description does not establish identical access in every route.

## Test text before adding media

Ask Vale to explain what happens before visiting the archive. The reply should preserve the visitor's undecided action. Then ask for the next plant-observation task and check the setting and role without restating every canon fact in the question.

If the character places the glasshouse on the mainland, correct that fact only. Inspect the next replies for the setting and for unintended changes to Vale's occupation or style. Do not use a regenerated portrait as evidence that the text correction succeeded.

## Evaluate appearance as another output

If you choose an available permitted image feature, check the visible garment and setting against the visual part of the brief. Record its charge and any retries independently. Image similarity and narrative consistency answer different questions, even when the interface connects them to the same character.
