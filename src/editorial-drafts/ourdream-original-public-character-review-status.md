OurDream's help says characters go through review before being publicly accessible. Track the current state of an original character before sending a link. A draft in your profile and a page a reader can open serve different purposes.

## Prepare a useful submission record

For a fictional adult baker, keep the name, submission time and a short description of the intended audience. Read the provider's current content terms and check for any real-person or borrowed intellectual property details. If the character is still in review, use the time frame and support route in the current help instead of repeatedly resubmitting an identical draft.

![Record which character you submitted. Check the latest review status. Confirm the shared route.](/assets/editorial-ourdream-original-public-character-review-status.png)

## Confirm the audience sees the right profile

When publication becomes available, inspect the expected visible page through an appropriate view and compare its title and premise with your draft. Keep a local copy of the original writing. Use the visible link only after the character is ready to share.
